# Color System

Primary color is the brand logo color `#2E3192` (deep indigo). The palette is flat and low-glow: no gradients, no pure black or pure white, so the site feels designed by a human, not generated.

## Principles

- **Primary stays the logo color** in light mode: `#2E3192`.
- **Dark mode uses a lighter tint** of the same hue (`#8B90EE`) because `#2E3192` is too dim on dark backgrounds.
- **Backgrounds are tinted**, never `#000` or `#fff`.
- **Solid colors only.** No gradients, glows or blur blobs.
- **Gold accent** is used sparingly: underline, badge, small number.

## Setup (Tailwind v4 + next-themes)

### 1. `app/globals.css`

```css
@import "tailwindcss";

@custom-variant dark (&:where(.dark, .dark *));

:root {
  --background: #FAF9FD;
  --surface: #FFFFFF;
  --surface-alt: #F2F2FA;
  --border: #E1E2F0;
  --foreground: #15162B;
  --foreground-secondary: #55577A;
  --foreground-muted: #8A8CA8;
  --primary: #2E3192;
  --primary-hover: #25277A;
  --primary-soft: #ECECF8;
  --on-primary: #FFFFFF;
  --accent: #C9A24B;
}

.dark {
  --background: #0F1020;
  --surface: #181A30;
  --surface-alt: #131428;
  --border: #2A2D4A;
  --foreground: #EEEFF8;
  --foreground-secondary: #B3B5D1;
  --foreground-muted: #7F82A3;
  --primary: #8B90EE;
  --primary-hover: #A1A5F4;
  --primary-soft: #22254A;
  --on-primary: #0F1020;
  --accent: #D8B661;
}

@theme inline {
  --color-background: var(--background);
  --color-surface: var(--surface);
  --color-surface-alt: var(--surface-alt);
  --color-border: var(--border);
  --color-foreground: var(--foreground);
  --color-foreground-secondary: var(--foreground-secondary);
  --color-foreground-muted: var(--foreground-muted);
  --color-primary: var(--primary);
  --color-primary-hover: var(--primary-hover);
  --color-primary-soft: var(--primary-soft);
  --color-on-primary: var(--on-primary);
  --color-accent: var(--accent);
}

body {
  background-color: var(--background);
  color: var(--foreground);
}
```

### 2. Theme provider

```bash
npm install next-themes
```

`components/theme-provider.tsx`:

```tsx
"use client";

import { ThemeProvider as NextThemesProvider } from "next-themes";

export function ThemeProvider({ children }: { children: React.ReactNode }) {
  return (
    <NextThemesProvider attribute="class" defaultTheme="system" enableSystem>
      {children}
    </NextThemesProvider>
  );
}
```

`app/layout.tsx`:

```tsx
import "./globals.css";
import { ThemeProvider } from "@/components/theme-provider";

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en" suppressHydrationWarning>
      <body>
        <ThemeProvider>{children}</ThemeProvider>
      </body>
    </html>
  );
}
```

## Design rules

1. **No gradients, glow or blur blobs.** Flat color with a thin border.
2. **Accent gold** only for small details (underline, badge, number).
3. **Radius**: stick to `rounded-lg` / `rounded-xl`.
4. **Fonts**: `Fraunces` or `Instrument Serif` for headings, `Inter` or `DM Sans` for body.
5. **Spacing**: generous (`py-24`, `py-32`).
6. **Depth**: prefer borders over shadows.
